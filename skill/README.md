# pyxel workflow skill

Bundled Pyxel skill content for `pyxel-mcp publish-skill` and `pyxel://workflow` resources.

The public surface is intentionally small:

- `SKILL.md` for the default build/verify loop.
- `strict-mode.md` for optional release/audit evidence.
- `pyxel-notes.md` for concise Pyxel gotchas.

This is the same role as the standalone `pyxel-skill` repository, but versioned with the pyxel-mcp package that bundles it.
